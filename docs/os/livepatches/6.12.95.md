# Linux 6.12.95 livepatch coverage

This page applies only to vpsAdminOS systems booted with Linux `6.12.95`.
Livepatch availability and vulnerability coverage are specific to a boot
kernel; no coverage for other kernel versions is implied.

## Current livepatch

The current cumulative livepatch is **v6**. When active, it changes the kernel
release reported by `uname -r` from `6.12.95` to `6.12.95.6` and is loaded as
module `livepatch_6`.

| Item | Value |
| --- | --- |
| Boot kernel | `6.12.95` |
| Livepatch | v6 (`6.12.95.6`) |
| Reviewed stable range | `v6.12.95..v6.12.104` |
| Covered security fixes | 63 |
| Covered fixes with assigned CVEs | 46 |
| Kernel backports | [`vpsadminos-6.12.95-backports` at `fc37ccc43227`](https://github.com/vpsfreecz/linux/commit/fc37ccc43227ab8eef70b50660a081f2615d0ead) |
| vpsAdminOS integration | [`d9bd139cd` on `staging`](https://github.com/vpsfreecz/vpsadminos/commit/d9bd139cd3005657c5084dccda159b083ca9390d) |

V6 is cumulative: it retains all fixes from v1 through v5 and adds 16
security fixes. The **First livepatch** column below identifies the release
which first carried a fix; every listed fix is present in v6.

CVE assignments on this page were checked on 2026-08-22 against official Linux
vulnerability-data commit `d9dda40c8f21126303839427ebc8652167302488`.
Fixes which receive a CVE assignment later should be moved from the unassigned
list into the CVE table.
